# Task Tracker

## About the Project

Task Tracker is a simple web application created using HTML, CSS, and JavaScript.

It allows users to:
- Add new tasks
- Mark tasks as completed
- Delete tasks

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Open the project repository.
2. Download the project files.
3. Open `index.html` in a web browser.
